# solar-system-simulator
For my vocational final project, I was unsure about what kind of program to create.  I recalled that I was really into astronomy at the time, so I decided to build this simulation program—which also served to sharpen my calculation skills.

how to run :
you need a compiler like minggw64 or other compiler that make you comfortable. I run this with MSYS2 MingGW64
1. open minggw64 terminal
2. navigate to the folder where the program is stored. ex : cd C:/Downloads/sss
3. run Fct1.3.exe from minggw64 terminal. ex : ./Fct1.3.exe
